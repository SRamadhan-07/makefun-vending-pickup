A Python program — standard library only, no network — that writes one line to /output/entry.txt: a vending machine's pickup line to a passing human, asking if they are exact change, because it has waited all day for someone who does not make it give something back. The line is 108 characters, inside the competition's gate of 1 to 200 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
